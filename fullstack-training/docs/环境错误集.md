## 环境错误集

### 1.创建数据库

`mysql -u root -p -e "CREATE DATABASE fullstack_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"`

```bash
qihoodeMacBook-Pro:demo qihoo$ mysql -u root -p -e "CREATE DATABASE fullstack_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
Enter password:
ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: YES)

```

#### 问题描述

- 错误描述：尝试创建一个 MySQL 数据库，但根用户却出现了访问被拒绝的错误。
- 原因：根密码尚未设置（这是使用 Homebrew 安装 MySQL 时的常见情况）

#### 解决

1. 无需密码运行

```bash
mysql -u root -e "CREATE DATABASE fullstack_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

```

2. 设置 root 密码（生产环境推荐）

```bash
# 设置密码
  mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED BY '你的密码';"
  # 然后就可以用 -p 了
  mysql -u root -p -e "CREATE DATABASE fullstack_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

```
