# 全栈工程师转型培训 - 学习指南

## 培训概述

本培训为期8周，分为4个阶段，目标是让前端开发人员掌握Golang后端开发技能，后端开发人员掌握Vue3+Vite+TypeScript前端开发技能。

---

## 阶段一：跨技能入门期（第1周）

### 目标

- 前端人员：搭建Golang开发环境，掌握基础语法
- 服务端人员：搭建Vue3开发环境，掌握基础语法
- 双方：了解对方开发流程，完成简单的跨端联调

### 前端人员学习路径（学Golang）

#### Day 1: 环境搭建

1. 安装Go和IDE（GoLand或VSCode+Go插件）
2. 配置GOPATH、GOROOT环境变量
3. 理解go mod包管理机制（类比npm）
4. 初始化第一个Go项目

```bash
# 创建项目
mkdir my-first-go && cd my-first-go
go mod init my-first-go

# 运行程序
go run main.go
```

#### Day 2: 基础语法

1. 变量、常量、数据类型（对比JS）
2. 函数和结构体基础
3. 编写第一个Go程序

```go
// Go的变量声明（对比JS的let/const）
var name string = "hello"    // Go
// let name = "hello"        // JS

// Go的结构体（对比JS的class）
type User struct {
    ID       int    `json:"id"`
    Username string `json:"username"`
}
```

#### Day 3: 包管理和数据结构

1. go mod tidy（类比npm install）
2. 切片和映射（对比数组和对象）
3. net/http包基础

#### Day 4: Gin框架入门

1. 安装Gin框架
2. 路由配置（对比vue-router）
3. 编写第一个GET接口

```go
// Gin路由（对比vue-router）
r.GET("/api/user/list", handler.GetUserList)
// vue-router: { path: '/user', component: UserView }
```

#### Day 5: 复习与优化

1. 复习本周知识点
2. 完善路由配置
3. 优化接口响应格式

### 服务端人员学习路径（学Vue3）

#### Day 1: 环境搭建

1. 安装Node.js和VSCode
2. 配置Vue3+Vite+TS开发环境
3. 初始化Vue3项目

```bash
# 创建项目
npm create vite@latest my-admin -- --template vue-ts

# 安装依赖
cd my-admin && npm install

# 运行项目
npm run dev
```

#### Day 2: 基础语法

1. setup语法糖、ref/reactive（对比Go变量声明）
2. TypeScript类型定义（对比Go类型）
3. 编写第一个Vue3页面

```vue
<!-- Vue3的setup语法 -->
<script setup lang="ts">
import { ref } from "vue";
const count = ref(0); // 响应式变量（Go: var count int = 0）
</script>
```

#### Day 3: 组件和配置

1. 组件开发和通信（对比Go函数传参）
2. Vite配置
3. 集成Element Plus

#### Day 4: Vue Router入门

1. 路由配置（对比Gin路由）
2. 搭建后台管理基础布局
3. 实现路由切换

#### Day 5: 复习与优化

1. 复习本周知识点
2. 完善基础布局
3. 规范请求逻辑

```go
// bcrypt密码加密
func HashPassword(password string) (string, error) {
    bytes, err := bcrypt.GenerateFromPassword([]byte(password), bcrypt.DefaultCost)
    return string(bytes), err
}

// JWT令牌生成
func GenerateToken(userID uint, username, role string) (string, error) {
    claims := Claims{
        UserID:   userID,
        Username: username,
        Role:     role,
        RegisteredClaims: jwt.RegisteredClaims{
            ExpiresAt: jwt.NewNumericDate(time.Now().Add(24 * time.Hour)),
        },
    }
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
    return token.SignedString(jwtSecret)
}
```

## 关键知识点对照表

| 概念        | Golang                    | Vue3/TypeScript                              |
| ----------- | ------------------------- | -------------------------------------------- |
| 变量声明    | `var name string`         | `const name: string = ref('')`               |
| 函数        | `func add(a, b int) int`  | `function add(a: number, b: number): number` |
| 结构体/接口 | `type User struct {}`     | `interface User {}`                          |
| 数组        | `[]int{1, 2, 3}`          | `ref<number[]>([1, 2, 3])`                   |
| 对象/映射   | `map[string]int{}`        | `ref<Record<string, number>>({})`            |
| 路由        | `r.GET("/path", handler)` | `{ path: '/path', component }`               |
| 中间件      | `r.Use(middleware)`       | `router.beforeEach(guard)`                   |
| 状态管理    | 全局变量/结构体           | Pinia store                                  |
| 依赖管理    | `go mod`                  | `npm/package.json`                           |
