# 部署指南

## 环境要求

### 后端环境

- Go 1.19+
- MySQL 5.7+
- Git

### 前端环境

- Node.js 18+
- npm 9+

## 后端部署

### 1. 安装Go环境

```bash
# macOS
brew install go

# 验证安装
go version
```

### 2. 配置MySQL

```bash
# 安装MySQL
brew install mysql

# 启动 MySQL
brew services start mysql

# 关闭 MySQL
brew services stop mysql

# 重启 MySQL
brew services restart mysql

# 查看 MySQL 运行状态
brew services list

# 创建数据库
## 有初始密码用
mysql -u root -p352608ww -e "CREATE DATABASE fullstack_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

## 无初始密码
mysql -u root -e "CREATE DATABASE fullstack_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### 3. 初始化后端项目

```bash
cd backend

# 下载依赖
go mod tidy

# 修改数据库连接字符串（在database/database.go中）
# 默认连接字符串：root:password@tcp(localhost:3306)/fullstack_db?charset=utf8mb4&parseTime=True&loc=Local
# 请根据实际环境修改用户名和密码
```

### 4. 运行后端服务

```bash
# 开发环境
go run cmd/main.go

# 生产环境构建
go build -o fullstack-backend cmd/main.go

# 运行构建后的二进制文件
./fullstack-backend
```

### 5. 管理员账号

- 运行 init_admin.go 创建 admin 用户

```bash
# /backend
 go run cmd/init_admin.go
```

- 确认 MySQL 中是否有数据

```bash
mysql -u root -p352608ww -e "SELECT * FROM fullstack_db.users;"
```

后端服务默认运行在 `http://localhost:8080`

## 前端部署

### 1. 安装Node.js

```bash
# 推荐使用nvm管理Node版本
nvm install 18
nvm use 18

# 验证安装
node --version
npm --version
```

### 2. 初始化前端项目

```bash
cd frontend/my-admin

# 安装依赖
npm install
```

### 3. 运行前端开发服务器

```bash
npm run dev
```

前端开发服务器默认运行在 `http://localhost:5173`

### 4. 构建前端生产版本

```bash
npm run build
```

构建产物将输出到 `dist/` 目录

## Nginx部署（生产环境）

### 1. 安装Nginx

```bash
# macOS
brew install nginx

# Ubuntu
sudo apt-get install nginx
```

### 2. 配置Nginx

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/fullstack-training/frontend/my-admin/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 3. 启动Nginx

```bash
# 测试配置
nginx -t

# 启动Nginx
nginx

# 重启Nginx
nginx -s reload
```

## 常见问题

### 1. 数据库连接失败

- 检查MySQL服务是否已启动
- 检查数据库连接字符串是否正确
- 检查MySQL用户是否有足够权限

### 2. 前端跨域问题

- 开发环境：Vite代理已配置，无需额外处理
- 生产环境：Nginx代理已配置，无需额外处理

### 3. JWT令牌失效

- 默认令牌有效期为24小时
- 令牌失效后需重新登录

### 4. 端口冲突

- 后端默认端口：8080（可通过环境变量 PORT 修改）
- 前端默认端口：5173（可在 vite.config.ts 中修改）
